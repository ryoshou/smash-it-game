# Asset license log

Every model, texture, sound and font shipped under `Assets/_Game/Art/` or `Assets/_Game/Audio/` has one row here
(spec §12.4, a launch-bar item). `LicenseLogTests` fails when a file is missing or a row has no license.
Paths are relative to the project root.
