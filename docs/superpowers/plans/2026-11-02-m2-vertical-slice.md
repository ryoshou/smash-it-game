# Milestone 2 — Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A device build of Room 1 (Home Office) with its real look. It has the cat, four object types, five levels and full juice:
- **The cat:** it reacts to your shots.
- **Object types:** keycaps, coffee mugs, books and a potted cactus. Each has its own weight, sound and way of breaking.
- **Full juice:** breaking on the floor, pooled debris that fades away, per-material sound, VFX and confetti.
- **Sound:** real recorded sound effects and a music loop.

This is owner checkpoint 2 (spec §10a). It confirms the art direction and audio, and decides whether to keep the generated cat.

**Architecture:**
- M1's structure stays: rules are plain C# in `Core/` and `Levels/`, driven by EditMode tests, with thin MonoBehaviours.
- Breaking, debris fading, debris budget, shot tally and cat-reaction choice are new pure rules.
- Art comes in through two routes, and both land in `Assets/_Game/Art/` behind one import rule set and one validator:
  1. **Pack models** (CC0) are copied in by a manifest script.
  2. **Generated models** come from Blender scripts in `tools/blender/`, built with one command.
- Per-material feel lives in a Juice-side `PropFeelLibrary`, so gameplay data never references sounds or VFX.
- Rooms are `RoomTheme` data.

**Tech Stack:**
- Unity 6000.6.0f1, URP and PhysX, as in M1.
- Built-in Animator, ParticleSystem and FBX import.
- Blender 5.2.3 LTS (`/Applications/Blender.app/Contents/MacOS/Blender`), run in background mode with its bundled Python and bmesh.

**Spec:** `docs/superpowers/specs/2026-10-26-cat-desk-smash-design.md`

**Owner decisions for this plan:**
- **M1 checkpoint (2026-11-01):** shot feel approved with default `ShotTuning`.
- **Props (2026-11-02):** use pack props wherever the packs have them. Blender scripts only make what the packs lack (keycaps, keyboard, monitor, office desk, slingshot, yarn ball, room shell) and pre-fracture the pack breakables.

## Review Focus

1. **A whole stack falls at once and a dozen breakables hit the floor in the same second.**
   - Active debris never exceeds `maxDebrisSets`; the oldest set is recycled; no instantiation happens during play.
   - Test: `ManyBreaks_ActiveDebrisNeverExceedsMax` (Task 5).
2. **Retry or Next is pressed while debris is fading or VFX are playing.**
   - Every piece and effect returns to its pool, and the new level starts clean.
   - Test: `LoadLevel_DuringDebrisFade_ReturnsAllDebris` (Task 5).
3. **A prop breaks on the floor in the same physics step it would have been marked cleared.**
   - It still counts as cleared exactly once.
   - Test: `BreakBeforeClearCheck_CountsTargetOnce` (Task 5).
4. **A pack model imports at the wrong scale or rotation (`fbx(unity)` vs `fbx`).**
   - The validator flags it, and every kind spawns upright and stable.
   - Tests: `Check_ScaleOutsideRange_Fails` (Task 1), `AllPropKinds_AreStableAtSpawn` (Task 4).
5. **The shot that clears the last target is also the one being judged as a miss.**
   - The cat celebrates; it never gets annoyed on a win.
   - Test: `For_WinningShot_Celebrates` (Task 9).

**Files:**

**Interfaces:**
- Produces:
  - `static bool BreakRule.ShouldBreak(BreakMode mode, bool isBroken, bool touchedFloor)`: true only for an unbroken, non-`None` prop touching the floor.
  - `static float DebrisFade.Scale01(float age, float holdSeconds, float fadeSeconds)`:
    - 1 while `age ≤ hold`, then smoothstep down to 0 at `hold + fade`.
    - Clamped, and safe when `fade = 0`.
  - `sealed class DebrisBudget(int capacity)`:
    - `int Acquire()` returns a slot, evicting the oldest when full.
    - `void Release(int slot)`
    - `int Active { get; }`
  - `ShotTuning` new fields:

    | Field | Default |
    |---|---|
    | `debrisHoldSeconds` | 1.2 |
    | `debrisFadeSeconds` | 0.6 |
    | `maxDebrisSets` | 6 |
    | `breakScatterImpulse` | 0.6 |
    | `propImpactMinSpeed` | 0.4 |

  - `GameEvents` new events:
    - `event Action<PropKind, Vector3, float> PropImpact` (kind, point, relative speed)
    - `event Action<PropKind, Vector3, BreakMode> Broke`
    - Each comes with a matching `Raise…`.
  - `DeskObject.Init(bool isTarget, float deskTopY, Bounds playVolume, ShotTuning t, PropKind kind, BreakMode mode, GameEvents events)`
    - `OnCollisionEnter`:
      - Raises `PropImpact` when the relative speed is ≥ `propImpactMinSpeed`.
      - When the other collider has `FloorSurface` and `BreakRule` says so: first latches `Cleared` if not yet cleared, then raises `Broke`.
      - `Shatter`: asks the `DebrisPool` and deactivates itself.
