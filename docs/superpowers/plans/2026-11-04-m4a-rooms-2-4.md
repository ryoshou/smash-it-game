# Milestone 4a — Rooms 2–4 (Content) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a device build with all 100 levels (spec §6.1), for an owner content check before M4b. It includes:
- **Three new rooms:** Café (levels 26–50), Library (51–75), Gaming Den (76–100). Each has its own backdrop, desk look and music.
- **Nine new object types:** about one every 8 levels (spec §6.1), each with its own sound, break effect and mass (spec §9). One of them is the "fizzy soda" special: it bursts when knocked over (spec §6.2).
- **The playtest bot on every level.** All 100 levels pass their clear-rate bands (spec §6.3, §9).
- **Two M3 carry-overs:**
  - Pausing cancels a pull you are holding.
  - The debug panel only exists in development builds.

**Architecture:**
- M3's structure stays. The rules are plain C# with EditMode tests; MonoBehaviours stay thin.
- **Levels:**
  - Each room writes its own `LevelList` (`Room<N>LevelList.asset`, 25 levels).
  - A new `GameLevelList.asset` joins the four lists in order. It is what the game plays.
  - Level ids use the global number: `R2_L26` … `R4_L100`.
  - Save indices 0–24 still mean Room 1, so M3 saves carry over.
- **Rooms:**
  - `RoomTheme` and `RoomPresenter` already swap the backdrop, background colour and music per level.
  - The play desk's *look* moves into each room's backdrop prefab. The scene's `Desk` keeps only its collider.
  - Each room has an editor builder: `HomeOfficeBuilder`, `CafeBuilder`, `LibraryBuilder` and `GamingDenBuilder`. Their shared helpers move into `RoomKit`.
- **Fizzy soda:**
  - It uses a new `BreakMode.Burst`.
  - A pure `FizzRule` in `Game.Core` decides when it arms.
  - A `FizzFuse` MonoBehaviour on the fizzy prefab does the burst. It uses the same radial impulse as the ball's first-contact burst (`ImpactMath.BurstImpulse`).
  - A burst counts as cleared.

**Tech Stack:** Unity 6000.6.0f1, URP, PhysX, NUnit EditMode/PlayMode, Blender 5.2 generators. No new packages.

**Spec:** `docs/superpowers/specs/2026-10-26-cat-desk-smash-design.md`

**Owner decisions for this plan:**
- **Checkpoint 3 (2026-11-03):** passed ("Everything is all good for me now"). The L5 change, the back desk at z 1.2, and the bot policy and bands are approved and frozen.
- **Split (2026-11-03):** M4 is split into M4a (rooms and levels, no SDKs) and M4b (MAX, IAP, consent/ATT, Firebase and the final cat).

  - No `Find` at runtime, no allocations in `Update`/`FixedUpdate`/`OnCollisionEnter`.
  - Files under 400 lines: split layouts into one file per half-room.

  - TDD for every pure rule. ≥ 80% line coverage of `Game.Core`, `Game.Levels` and `Game.Meta`.
  - Headless runs only (`tools/unity/batch-tests.sh`), with the editor closed.
- **iOS only.**
